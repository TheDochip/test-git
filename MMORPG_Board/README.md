# MMORPG Board

Доска объявлений для фанатского сервера MMORPG на Django 6.1.

## Что умеет

| Требование ТЗ | Где сделано |
|---|---|
| Регистрация по e-mail с кодом подтверждения | `views.register`, `views.verify_email`, `views.resend_code`; код живёт 10 минут, привязан к пользователю |
| После регистрации — создание и редактирование объявлений | `views_board.post_create`, `post_edit` (редактировать может только автор) |
| Заголовок + текст с картинками, видео и др. контентом | Визуальный редактор TinyMCE, загрузка картинок в `/media/`, видео с YouTube / VK Видео / Rutube / Vimeo |
| Обязательная категория из 10 вариантов | `Post.Category`, фильтр по категориям на главной |
| Отклики (простой текст) на чужие объявления | `views_board.post_detail`; на своё объявление откликнуться нельзя |
| E-mail автору объявления при новом отклике | `emails.send_new_reply_notification` |
| Приватная страница откликов: фильтр по объявлениям, удаление, принятие | `/replies/` — `views_board.my_replies`, `reply_accept`, `reply_delete` |
| E-mail автору отклика при принятии | `emails.send_reply_accepted_notification` |
| Новостные рассылки | Админка → «Рассылки» → действие «Отправить выбранные рассылки» |

Безопасность HTML: текст объявления проходит через `board/sanitizer.py`. Это белый список тегов: `<script>`, обработчики `on*`, `javascript:`-ссылки и iframe с посторонних сайтов вырезаются.

Игровая часть (персонаж, квесты, бои, инвентарь) осталась без изменений, в неё ведёт пункт меню «Персонаж».

## Запуск

```bash
python -m venv venv
venv\Scripts\activate          # Windows  (Linux/macOS: source venv/bin/activate)
pip install -r requirements.txt

copy .env.example .env         # и заполнить своими данными
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Если в `.env` не указан `DB_NAME`, используется SQLite. Без указанного `EMAIL_HOST` письма (коды, уведомления, рассылки) выводятся в консоль `runserver`.

Суперпользователю, созданному через `createsuperuser`, для входа на сайт нужно подтвердить e-mail. Можно поставить галочку «email verified» в админке, или при входе придёт код.

## Рассылка

1. `/admin/` → «Рассылки» → «Добавить»: указать тему и текст.
2. В списке рассылок отметить её, выбрать действие «Отправить выбранные рассылки всем пользователям».

Письмо получит каждый пользователь с подтверждённым e-mail, каждому оно уходит отдельно. Уже отправленную рассылку повторно не отправить.
