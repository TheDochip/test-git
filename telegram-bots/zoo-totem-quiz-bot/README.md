# 🐾 Zoo Totem Quiz Bot

Telegram-бот-викторина «Какое у вас тотемное животное?» для Московского зоопарка.
Пользователь отвечает на 8 вопросов, бот подбирает одно из 20 животных зоопарка,
рассказывает о нём и о программе опеки, показывает ещё 3 близких животных.

## Возможности
- Inline-кнопки: ответы редактируют одно сообщение, чат не засоряется
- Прогресс-бар, отмена в любой момент, «Пройти ещё раз», кнопка «Поделиться результатом»
- Защита от нажатий на кнопки устаревших вопросов
- Взвешенная система баллов: каждый ответ даёт 1–3 балла нескольким животным

## Балансировка результатов
В первой версии часть животных (жираф, носорог, бегемот, зубр) **не выпадала никогда**,
а волк выпадал в 23% случаев. Я написал перебор всех 4⁸ = 65 536 вариантов ответов и
подобрал веса так, чтобы каждое животное выпадало в 3,6–6% случаев. Баланс закреплён тестом
`test_results_are_balanced` — он упадёт, если правка вопросов снова перекосит результаты.

## Стек
Python 3.10+, pyTelegramBotAPI, python-dotenv, unittest

## Архитектура
| Файл | Назначение |
|---|---|
| `bot.py` | обработчики Telegram и клавиатуры |
| `quiz.py` | `QuizSession` (состояние, подсчёт баллов, результат), валидация данных |
| `quiz_data.py` | 20 животных и 8 вопросов с весами |
| `tests/` | 11 тестов: целостность данных, баланс, сценарии прохождения |

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env    # BOT_TOKEN, по желанию BOT_USERNAME
python bot.py
```

## Тесты
```bash
python -m unittest discover -s tests
```
